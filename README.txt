IRONFORGE — site + PHP + MySQL (XAMPP)
Saves the contact form into the `users` table (Fullname, Email, Yourgoal, Message) of the `contact` database.
1. Copy this folder to C:\xampp\htdocs\ironforge
2. Start Apache and MySQL in XAMPP.
3. Set the admin password hash in config.php.
4. Open http://localhost/ironforge/  (check DB: /test_db.php, inbox: /admin.php)
